3. 字段语义速查

同名状态处于不同层时，语义不能混用。

Identity

artifact.id
Core 派生的源对象身份。
source_digest
候选引用的源正文字节摘要。
manifest_digest
Host 准入的 Provider 配置修订。

Transformation

boundary
AW 公共 Tool 边界。
seam
Tokenless 对同一边界的 native 表达。
transform_chain
形成 candidate 的变换链。

Settlement

applied
Tokenless native 调用产生输出。
produced
Host 形成 canonical candidate。
adopted
Environment 最终采用；当前缺少独立回执。
Review boundary
当前跨 Contract 的主要矛盾是 lossless。 AW 将它定义为保留全部 source information；Tokenless 允许删除 debug、trace 或空字段后仍称为 lossless。 修复时应保留 AW 的强定义，并在发生字段删除时返回不可逆状态或提供可恢复证据。 此图展示 PR head 的真实返回值，不表示该语义矛盾已经解决。
