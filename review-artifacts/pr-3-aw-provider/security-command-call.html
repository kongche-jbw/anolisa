不能越过的声明边界

当前 Provider/schema 路径能证明 Agent Sec 对它收到的 38B 返回了结构化 warn；它不能独立证明 执行器随后执行的仍是这 38B。任何 E2E 演示都应把 STEP 01 与 STEP 07 标为待接线，直到 COSH 提供可信、不可被通用脱敏 hook 替代的 PreTool 执行边界。
